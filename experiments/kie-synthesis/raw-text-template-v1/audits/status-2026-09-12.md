## Measured core inefficiencies

The original transfer-200 v12 trace cost $25.84332216 across 1,584 requests. Its retained trace
contains 46,064,142 input, 13,496,983 output, and 6,668,868 reasoning tokens.

1. **Rejected work dominates.** Host-rejected stages cost $13.11364013, or 50.74% of the bill.
   This is an upper bound on addressable waste, not a promise that every rejection is avoidable;
   some critic revisions found real defects.
2. **The schemas express illegal combinations.** There were 155 paid compiler retry responses,
   costing exactly $1.85275953. Their 360 retained validation defects were exclusively the two
   conditional render-mode invariants that the flat schema could not express. A live GLM critic
   also emitted `pass` with patch data and required a $0.000321685 retry.
3. **The critic is sent a duplicated state snapshot.** Across 765 critic calls, current user
   payloads total 76,198,300 bytes. Binding inventory is 67.70%; inventory, masked template,
   target paths, and removal keys together are 95.12%. A lossless short-ID representation is
   42,939,485 bytes, a proven 43.65% reduction, and round-trips every payload exactly.
4. **Repair prompts resend unchanged state.** In compiler repair payloads, the full prior candidate
   is 36.41%, unchanged anchors 27.99%, and risk candidates 12.61%.
5. **Caching did not save money in this trace.** At the recorded Luna rates, actual cache classes
   cost $0.43411416 more than pricing every input token at the ordinary input rate because cache
   writes were charged at 1.25x. This is provider/model specific; the structural payload problem is
   not.
6. **Atomic semantic edits create ping-pong.** A multi-finding patch is rejected as a whole when
   one exact span or ownership operation is wrong. Valid independent corrections are then resent,
   and the next critic often rediscovers a different repeated-page component.

The costs above overlap and must not be added. The $1.85275953 retry cost is exact and immediately
addressable; the $13.11364013 rejected-stage cost is a much larger optimization ceiling whose
recoverable fraction needs a paired experiment.

For orientation only, subtracting the observed transfer-v12 retry cost per document from the
current projections yields $224.358778842717 for 1,650 and $295.609688002465 for 2,174 documents.
Halving host-rejected spend instead would yield $185.550279428967 and $244.476549987015. Eliminating
all rejected-stage spend would be an unrealistic ceiling of $131.456513892717 and
$173.203915880465. These scenarios overlap, assume the transfer sample generalizes, and are not
optimized cost claims; the paired 30-document canary must replace them with measured rates.

## Offline contract probes

The experimental provider-neutral contracts were evaluated over every retained accepted output and
invalid retry input without provider calls:

- 37,454 accepted legacy binding proposals translated to a render-mode-discriminated schema with
  zero rejection.
- All 360 retained invalid compiler binding inputs are structurally excluded.
- 763 accepted legacy critic outputs translated to verdict-discriminated pass/revise schemas with
  zero rejection.
- The live invalid pass-with-patch critic output is structurally excluded.
- All 765 compact critic payloads round-tripped to byte-semantically identical JSON objects.

The stronger schemas are larger: +2,896 bytes for the binding schema and +3,581 bytes for the
critic schema. That is a deliberate trade: a modest fixed schema increase prevents long invalid
outputs and paid repair responses. Stable host occurrence IDs were also prototyped so models can
select a verified span rather than reconstruct source text, casing, line ranges, and duplicate
indexes.

## Provider-neutral optimization plan

Ranked by confidence and breadth:

1. **Host-owned occurrence vocabulary.** Pre-enumerate exact candidate spans and give the model
   stable occurrence IDs. Provider output selects IDs; it never copies quotations, line ranges,
   occurrence indexes, casing, or Unicode. This directly removes the largest original failure
   family.
2. **Discriminated output contracts.** Promote the tested render-mode and critic-verdict variants.
   Illegal fields are absent from each branch rather than rejected after generation.
3. **Compact immutable provider view.** Replace repeated paths, logical keys, source-binding IDs,
   and occurrence objects with short stable tables. Maintain a host-only canonical state and prove
   lossless expansion before every call.
4. **State-hashed component transactions.** Express changes against a specific inventory hash and
   partition non-overlapping findings into independently verifiable connected components. Commit
   only complete valid components, then rerun global ownership and completeness certification.
   This preserves atomic correctness without discarding unrelated valid repairs.
5. **Repeated-layout propagation.** Detect exact/near-exact repeated form blocks, have the agent
   solve one canonical block, and deterministically project verified relative spans across repeats.
   Every projected occurrence must still pass exact source and topology gates. This targets the
   12-page hard case rather than asking a model to enumerate the same form 6–12 times.
6. **Delta repair protocol.** Repairs reference stable binding/occurrence IDs and transmit only the
   changed component plus the host rejection, not the full previous candidate, anchors, and risks.
7. **Separate discovery from mutation.** Keep an independent semantic critic, but convert its
   grounded findings into host-generated bounded edit choices wherever deterministic resolution is
   possible. Use an agent repairer only for the residual ambiguous component.
8. **Expand deterministic renderer adapters.** Add measured adapters for recurring auxiliary
   identifiers, fixed affixes, repeated projections, compact equipment forms, counts, and
   party/cargo groups. The goal is fewer `agent_required` descendants, not merely cheaper
   preprocessing.
9. **Tiered model/provider routing last.** Compare routes only after the protocol is fixed, and
   score total compiler+critic+retry cost, latency, certification, manual semantic quality, and
   final agent-assisted bindings. Model name alone is not a routing decision; endpoint behavior
   matters.

## Next experiment and gates

The next experiment should isolate protocol improvement from model choice:

1. Implement items 1–6 only inside this experiment and replay all retained traces offline.
2. Require exact source reconstruction, target ownership, carrier binding, topology, and final
   critic invariants to remain unchanged or become stricter.
3. Run a paired 30-document canary with the same Luna provider/model on old versus optimized
   contracts. Include easy, multi-page, multi-container, DG, duplicate-short-value, and the current
   12-page hard-case strata.
4. Require 30/30 certification, no manual-review defect, no increase in agent-assisted bindings,
   fewer paid retries, lower total accepted cost, lower wall time, and no memory regression.
5. Only after that isolation test, run a paired route canary for Luna and selected GLM endpoints.
   Then validate transfer on 100 documents.

No full-source preprocessing should start until these gates pass and the user gives the separate
scale flag.
