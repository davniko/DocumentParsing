# Reusable synthesis templates

Keep admitted, reusable templates here, separate from generation campaigns,
experiments and review drafts. Sampling registries remain in `artifacts/registries/`.

- [Current MPCI V7 reviewed catalog](mpci-bl-v7-reviewed/README.md): 100 admitted
  source families; shared rendering declarations, source snapshots and manifest.

Newly reviewed compatible families can join that catalog. A different target
schema or incompatible rendering policy should have its own explicitly named
catalog; do not silently replace an existing source contract.

Only catalog documentation, declarations and the hash inventory are versioned.
Document-derived assets and generated datasets retain the repository's existing
local-artifact policy.
