## 2. Validation versus real training: exact scope and method

Dataset: `data/curated/mpci-bl-real600-synthetic7000-country-presentations-r27-positions-v1`.
Compared **all 36,000 validation/real pairs**, not a random subsample.

- Exact source ID, raw SHA-256, positioned SHA-256, normalized raw text, and PDF
  SHA-256. Original PDF links were resolved for all 660 documents and their
  actual bytes hashed. No PDF-content OCR or fresh visual PDF adjudication was
  needed for these identity checks.
- Role-scoped names, goods descriptions, B/L/master B/L, containers, seals,
  phone digits, email, HS digits, vessels, voyages and issue dates.
- Name/description equality here is punctuation/case/accent-insensitive,
  whitespace-normalized token equality, retaining token order. It is not an
  external entity-resolution system. `PLSTONE` and `PL STONE` remain different
  exact strings; fuzzy content review still identifies that family.
- Three reproducible TF-IDF cosine screens: complete raw OCR; private content
  (shipper/consignee/notify names and postal addresses plus goods descriptions);
  goods descriptions alone. Sublinear TF, smoothed IDF, unigrams+bigrams, L2
  normalization over these 660 documents. Private content excludes carrier
  boilerplate, delivery agents, B/Ls, dates and container identifiers.
- Broad candidate review triggers: raw cosine ≥0.85, private-content cosine
  ≥0.75, shared bill/container/seal, or both primary party names matching within
  the same pair. All 55 resulting pairs' targets, identifiers, dates and quantities
  were compared; representative family raw OCR and the shared-container raw
  pair were opened. This is not a claim of visually opening all 660 PDFs.
- Known labeled bill/container identities were searched in the opposite
  split's raw OCR too. Short legitimate charter B/Ls (`2`, `7`, `13`) require
  a B/L caption, not a match to an unrelated page/date/quantity. Digit-bearing

## 3. Does overlap explain the real-data benefit?

Reusing the earlier saved **own-reference, unchanged non-HS counts**, not rescoring
historical predictions against current R27 gold, gives this cohort breakdown:

| Cohort in the same parseable L/M intersection | Documents | L synthetic-only F1 | M real-added F1 |
| --- | ---: | ---: | ---: |
| Has an exact same-role shipper or consignee in current real training | 17 | 0.8584 | 0.9304 |
| No such exact primary-party match | 39 | 0.8613 | 0.9080 |
| No exact primary-party match **and** no exact goods-description match | 35 | 0.8582 | 0.9050 |
| Both primary parties and goods match one real source | 4 | 0.9067 | 0.9769 |

In the strictest displayed unmatched cohort, correct non-HS facts increase
**1,235 → 1,310 of 1,450**, with predicted values 1,428 → 1,445. Therefore
real-data benefit is **not confined to repeated exact party/goods values**.
The larger gain for overlapping parties is also observable and should not be
ignored when describing validation independence.

This is a descriptive subgroup analysis on a small existing validation set,
not a randomized intervention or a pure unseen-entity benchmark. A spelling
variant, shared address, carrier or other related feature can survive the exact
name screen. The 35 documents are not guaranteed wholly unrelated businesses.
The analysis neither quantifies a memorization fraction nor establishes that
current synthetic repairs have eliminated the real-data benefit.

## 4. Recommendations and boundaries

1. Keep current accepted country/package edge cases unchanged; no repair is needed.
2. Before treating validation as unseen-shipment evidence, decide how to handle
   the single shared physical-container group. Preserve existing historical scores.
3. Keep the existing benchmark for longitudinal comparison, but add a future
   shipment-/party-group-disjoint evaluation if claiming unseen-business generalization.
   Repeated carrier layouts alone need not be excluded: parsing known forms is
   part of the intended task.
4. Finish the bounded phone-list completeness adjudication separately. Do not
   silently change validation or label every gold-absent model number a hallucination.
5. The next data work should target the remaining role/level/boundary contrasts,
   not assume the format repairs prove synthetic-only equivalence. The planned
   surgical real-data anonymization remains useful; it is not implemented here.
